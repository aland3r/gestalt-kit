## The Invariant

**All agents, skills, commands, and documentation MUST live in `gestalt-kit/`.**

- `doc/` and `gestalt-vault/` are **redirects only** — no new content there.
- `.cursor/skills/` contains **thin pointers** (auto-generated adapters) — SoT is `gestalt-kit/skills/{name}/`.
- `.claude/worktrees/*/` may have transient agent state — not authoritative.

## Checklist for Future Sessions

- [ ] Create definition in `gestalt-kit/agents/` or `gestalt-kit/skills/{name}/` (with SKILL.md + reference.md)
- [ ] Add entry to `gestalt-kit/AGENTS.md` index
- [ ] Run `node scripts/sync-cursor-adapters.mjs` to regenerate `.cursor/skills/` adapters
- [ ] Verify `git status` shows only `gestalt-kit/` and `.cursor/skills/` files changed — nothing in `doc/` or `gestalt-vault/`
