# Deviante Figma — páginas `use cases`

Skill Cursor: `.cursor/skills/deviante-figma-use-cases/SKILL.md`

## Regra absoluta

Nas páginas **`use cases`** do Deviante v1.0, **absolutamente nada** (exceto o **frame da tela**) pode existir sem vínculo a componente que passa pela **library Deviante** e pela **library mãe ADS** (Alander Design System).

- **ADS:** componente originário **sem estilo** de produto
- **Deviante library:** componente estilizado (link ADS + tema)
- **Deviante styles:** onde se aplica o visual do produto
- **use cases:** só **frames de tela** preenchidos com **instâncias** da library Deviante

## Cadeia

```
ADS (sem estilo) → Deviante library (estilizado) → use cases (frames + instâncias)
```

## Proibido em use cases

Texto solto, shapes locais, detach, instância direta do ADS, estilizar na página, controles desabilitados ou opções fora do escopo da versão.
